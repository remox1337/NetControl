# NetControl

**Internet für ein bestimmtes Programm per Hotkey ab- und wieder anschalten (Windows).**

</div>

---

## Download

Neueste Version unter [**Releases**](../../releases/latest) → `NetControl.exe` herunterladen und starten.
Das Programm benötigt Administratorrechte (für die Windows-Firewall-Regeln).

## Funktionen

- Internet eines einzelnen Programms per Hotkey sperren/freigeben
- Sperrt die ganze Prozessfamilie (gleichnamige Prozesse, Unterprozesse)
- Trennt bestehende Verbindungen sofort
- Ton beim Umschalten mit Lautstärkeregler
- Automatische Update-Prüfung über dieses Repository

## Bedienung

1. Programm per „Durchsuchen" oder aus der Liste laufender Programme wählen.
2. Mit dem Hotkey (Standard **F8**) oder dem großen Button das Internet sperren/freigeben.
3. Hotkey und Optionen lassen sich im Fenster anpassen; Einstellungen werden im Benutzerprofil gespeichert.

Beim Beenden wird das Internet automatisch wieder freigegeben.
