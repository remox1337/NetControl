# NetControl

Internet fuer ein bestimmtes Programm per Hotkey ab- und wieder anschalten (Windows).

## Download
Neueste Version unter **Releases** -> `NetControl.exe` herunterladen und starten.
Das Programm benoetigt Administratorrechte (fuer die Windows-Firewall-Regeln).

## Funktionen
- Internet eines einzelnen Programms per Hotkey sperren/freigeben
- Sperrt die ganze Prozessfamilie (gleichnamige Prozesse, Unterprozesse)
- Ton beim Umschalten mit Lautstaerkeregler
- Automatische Update-Pruefung ueber dieses Repository
